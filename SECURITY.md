# Security Policy

## Supported Versions

Security fixes are provided for the latest stable release of this project. Older versions may not receive security updates.

| Version | Supported |
| --- | --- |
| Latest stable release | Yes |
| Older releases | No |

If this project has not published a release yet, security fixes are applied to the default branch.

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues, discussions, or pull requests.**

To report a suspected vulnerability:

1. Open the repository's **Security** tab and select **Report a vulnerability**.

Please include, when possible:

- A description of the vulnerability and its potential impact.
- The affected versions, components, or configurations.
- Steps to reproduce the issue or a minimal proof of concept.
- Any suggested mitigation or fix.

Do not include sensitive personal data, credentials, or secrets in your report.

## What to Expect

Im a solo dev, so i will do the best i can to acknowledge reports within reasonable time, assess their severity, and provide updates as the investigation progresses. Resolution time depends on the nature and complexity of the issue.

I ask reporters to allow reasonable time for remediation before publicly disclosing details. I will coordinate disclosure when possible and credit reporters if they wish to be acknowledged.

## Responsible Security Research

When investigating potential vulnerabilities:

- Act in good faith and avoid disrupting services or other users.
- Do not access, modify, or delete data that does not belong to you.
- Do not perform denial-of-service attacks, social engineering, or intrusive automated testing.
- Stop testing and notify us if you encounter sensitive information.

Thank you for helping keep this project and its users secure.
