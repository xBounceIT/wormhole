### Session tab list (`SessionTabBarState`)

Pure state for the sessions strip keyed by [`SessionId`](../../rust/crates/wormhole-ui/src/session_tab_bar.rs) (UUID newtype; caller supplies on open — typically `wormhole_session::SessionId` via app glue). Each [`SessionTabModel`](../../rust/crates/wormhole-ui/src/session_tab_bar.rs) holds `title` + [`ProtocolBadge`](../../rust/crates/wormhole-ui/src/session_tab_bar.rs) (`SSH` / `RDP` / `HTTP` / `HTTPS` / `Serial` / `VNC`, 1:1 with domain `ProtocolType`).

| Op | Behavior |
|---|---|
| `open(id, title, badge)` | Append + activate; `DuplicateSession` if id already open (state unchanged) |
| `activate(id)` / `close(id)` | `UnknownSession` if missing (fail-closed); close of active picks neighbor at same index (first → new first, last → previous, only → `None`) |
| `set_title(id, …)` | Rename without touching badge / id; same soft title sanitize as `open` |

Titles are soft-handled: Unicode control chars (NUL / C0 / C1 / DEL) are stripped; empty titles are allowed (never rejected).

**Orchestrator glue (app crate):** `wormhole-app` (`session` + `ui` features) exposes pure helpers in [`session_tabs.rs`](../../rust/crates/wormhole-app/src/session_tabs.rs):

| Helper | Direction | Notes |
|---|---|---|
| `open_tab_for_session` / `close_tab_on_session_closed` | orch → tab chrome | UUID bit map via `to_ui_session_id` / `from_ui_session_id`; open fail-closes on duplicate; close-on-session-closed is **idempotent** (unknown id → `Ok`) |
| `close_tab_and_dispose` / `close_tab_and_dispose_session` | tab close → orch | Closes chrome, cancels `CancellationToken` (in-flight connect), awaits [`SessionHandle::close`](../../rust/crates/wormhole-session/src/orchestrator.rs) (tunnel lease drop). [`SessionBindings`](../../rust/crates/wormhole-app/src/session_tabs.rs) maps `SessionId` → cancel + optional handle. Unknown binding → no-op; handle id mismatch → **fail-closed** (no side effects). `attach_handle` after connect: absent binding → dispose orphan (mid-close race); already-connected → **fail-closed** `DuplicateBinding` (new handle closed). |

Prefer a stable id before connect via `ConnectOptions.session_id` so the tab + binding share the same UUID while `Connecting`. No GPUI window — unit-tested with Fake serial/SSH/tunnel. See [16-session-orchestrator.md](16-session-orchestrator.md).

**Not GPUI chrome:** `SessionTabBarState` is pure Rust state only. The optional `--features gpui` lab still drives its tab strip from `TabStrip` / `SessionTab` (generated UUIDs + pane assignment) — shipping `SessionTabBarState` into GPUI is a later wiring step.

### Pane layout tree (`PaneLayout`)

Pure recursive binary tree on [`PaneLayout`](../../rust/crates/wormhole-ui/src/pane_layout.rs): `Leaf(PaneId)` or `Split { axis, ratio, first, second }`.

| Op | Behavior |
|---|---|
| `split` / `WorkspaceState::split_directed` | Split a leaf along `SplitAxis::Vertical` (side-by-side) or `Horizontal` (stacked); new pane is the second child; ≤4 panes; auto-allocates lowest free `PaneId` |
| `split_with` | Same tree op with caller-owned `new_pane`; already present → `DuplicatePane` |
| `merge` / `close_pane` | Remove a leaf and promote its sibling subtree (unsplit parent); last pane refused; failed ops leave state unchanged |
| `set_ratio_for_pane` / `set_split_ratio` | Adjust the **immediate parent** split’s first-child ratio (nested quad root with two split children is not reachable via a leaf’s immediate parent) |

**Ratios:** finite values clamp to `[0.15, 0.85]` (inclusive); **NaN / ±Inf rejected** (`UiError::InvalidSplitRatio`) — no silent coerce (chrome drag helpers may coerce; the state machine does not). Flat [`WorkspaceState::panes`](../../rust/crates/wormhole-ui/src/workspace.rs) is **insertion order** (append on split; relative order preserved on close) so GPUI chrome + [`PaneLayoutSink`](../../rust/crates/wormhole-ui/src/layout_sink.rs) / `BrokerPaneLayoutSink` ticks stay compatible — that order can diverge from DFS [`PaneLayout::leaves`](../../rust/crates/wormhole-ui/src/pane_layout.rs) after nested splits; the leaf **set** stays equal. Coarse [`PaneArrangement`](../../rust/crates/wormhole-ui/src/pane_layout.rs) (`Single` / `VerticalSplit` / `HorizontalSplit` / `Quad`) remains count-derived for tile presets.

Optional `--features gpui` links the Zed `gpui` + `gpui_platform` pins and renders shell chrome driven by `ShellState`.
Optional `--features storage` wires `StorageConnectionSource` to `wormhole-storage` reads.

**Invariant:** `pane_count() ≤ 4`. Closing a pane does not renumber survivors (so tab → pane links stay valid); `ShellState::close_pane` / `merge_pane` clears assignments that pointed at the closed id.

## GPUI chrome (`--features gpui`)

Boot via `gpui_platform::application()` (same pattern as surface-lab gates 1–2). Lab entry:

```powershell
cargo run -p wormhole-ui --example wormhole-ui-lab --features gpui
```

Layout (plan ASCII):

```text
┌──────────────────────────────────────────────────────────┐
│ Wormhole          Quick Connect (stub)         [—][□][×] │
├────────────┬─────────────────────────────────────────────┤
│ Connections│ [tab] [tab*] …                              │
│ Credentials├─────────────────────────────────────────────┤
│ Sessions   │  pane slots (1..=4 from ShellState)         │
│ Tunnels    │                                             │
│ Settings   │                                             │
└────────────┴─────────────────────────────────────────────┘
```

| Region | Behavior |
|---|---|
| Title / quick-connect strip | Custom transparent title bar + Quick Connect stub; Mica backdrop |
| Sidebar | `SidebarRegion::ALL` list; click selects region on `ShellState` |
| Tab strip | Tabs from `TabStrip`; `+` opens a demo tab; `Split` / `Close pane` call shell actions |
| Workspace | 1 / 2 / 3 / 4 pane tiles from `WorkspaceState`; focus click updates shell |
| Layout sink | Each layout change computes physical pane slots → `PaneLayoutSink::on_pane_layout` (identical ticks skipped) |

Public GPUI entry points: `try_boot_shell`, `try_boot_shell_with_sink`, `ShellChrome`, `LogicalRect`, `GpuiShellMarker`.

**Do not claim hardware gate pass** from this lab alone — DPI / Mica evidence stays on [gate-checklist.md](gate-checklist.md) / surface-lab.

### Broker wiring (out of this crate)

`wormhole_surface_win` (`--features pane-layout`) provides `BrokerPaneLayoutSink`:
bind `PaneId` → `SurfaceHandle` (WebView2 / RdpActiveX), then each
`on_pane_layout` tick calls `NativeSurfaceBroker::update_bounds` with
`PhysicalBounds`. Degenerate / omitted / unbound / unbind / rebind contracts are
unit-tested against `StubNativeSurfaceBroker`; surface-lab smoke via
`--features pane-layout` (see [01-surface-lab.md](01-surface-lab.md)). Lab smoke
is **not** a hardware gate-checklist or DPI soak pass.

Same feature also exposes pure **pane focus glue** (`activate_pane` /
`cycle_pane_focus`): updates [`WorkspaceState`](../../rust/crates/wormhole-ui/src/workspace.rs)
focus (empty / unknown pane fail-closed; workspace-idempotent when already focused)
and syncs `FocusCycle` to the pane binding — bound surface, or chrome sentinel when
unbound — emitting a `FocusRequest` for `FocusBroker` only when the broker target
changes within the call (including rebind / late-bind under the focused pane). HWND
map updates while already current are out of band (`request_for_current` + broker).
No GPUI chrome and no rewrite of the layout-sink tick path. See
[native-surface-broker.md](native-surface-broker.md).

**Session surface glue** (`open_session_surface` / `close_session_surface`): maps
[`SessionId`](../../rust/crates/wormhole-ui/src/session_tab_bar.rs) open/close onto
Fake broker register+bind / unbind+dispose. Duplicate session and pane-in-use
fail-closed on open; close is idempotent for unknown session; unknown surface at
dispose fail-closed (registry dropped); other dispose errors keep the registry
for retry. Pure stub — no live HWND / WebView2. See
[native-surface-broker.md](native-surface-broker.md). Ledger:
[adversarial-ledger-broker-session-surface.md](adversarial-ledger-broker-session-surface.md).

**Pane split/merge notify glue** (`split_and_notify` / `merge_and_notify` /
`split_with_and_notify`): after a successful [`WorkspaceState`](../../rust/crates/wormhole-ui/src/workspace.rs)
split or merge, emits one [`PaneLayoutSink`](../../rust/crates/wormhole-ui/src/layout_sink.rs)
tick (tree → physical slots via `physical_updates_for_layout`) into
`BrokerPaneLayoutSink` / Fake. Invalid ops fail-closed with existing
`UiError` (`DuplicatePane`, `UnknownPane`, `PaneLimitReached`, `InvalidSplitRatio`,
`LastPane`) and **do not** notify. `merge_and_notify_bound` unbinds the closed pane
(PaneId reuse safety); unbound `merge_and_notify` omit-hides only. No GPUI chrome;
does not rewrite `PaneLayout` / sink tick internals. See
[native-surface-broker.md](native-surface-broker.md). Ledger:
[adversarial-ledger-pane-split-notify.md](adversarial-ledger-pane-split-notify.md).
